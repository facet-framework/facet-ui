# Security reports for FACET UI

Report a suspected vulnerability through this repository's GitHub **Security →
Report a vulnerability** form when private reporting is available. If unavailable,
email <hello@facet-framework.com> with a short description and no exploit steps,
sensitive files or credentials in the first message. Discuss details privately.

Include the affected version, browser or runtime, a minimal synthetic reproduction
and observed impact. Avoid private repository data and access tokens.

Hosts remain responsible for validating untrusted data, enforcing authorization
and restricting network and filesystem access. UI presentation does not establish
that a test ran or that a record is accurate.

Security fixes are identified in tagged release notes. No response time or support
period is guaranteed.
