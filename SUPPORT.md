# Support

This repository is maintained by a single rights holder and publishes curated
releases. There is no support contract, response-time promise or support period;
see CONTRIBUTING.md for how changes are accepted.

- **Documentation** lives at <https://facet-framework.com> and in this
  repository's README and, where present, its `docs/` directory. Read the
  tagged README for the release you are using; `main` may describe a later
  candidate.
- **Questions** about a documented capability go through the _Question_ issue
  form. Name the release tag and include a minimal synthetic example.
- **Defects** go through the _Bug report_ issue form. Name the release tag,
  operating system and architecture, and give a reproduction with synthetic data.
- **Vulnerabilities** follow SECURITY.md. Never post exploit steps, sensitive
  files or credentials publicly; SECURITY.md names the private path and the
  fallback when that path is unavailable.
- **Licensing, conduct and anything that does not fit an issue** goes to
  <hello@facet-framework.com>.

Do not include credentials, private repository contents or another project's
records in an issue. Maintainers may ask you to confirm a report against the
current release before investigating.
